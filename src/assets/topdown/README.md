Fotos cenitales de las naves (vista desde arriba), una por flota, con la proa hacia arriba y fondo transparente.
Nombres: imperium, chaos, tau, aeldari, drukhari, orks, necrons, tyranids, daemons, votann, genestealer (.png o .webp).
Se generan con `python3 scripts/topdown.py <foto> <flota>`. Si falta alguna, la app usa la ilustración vectorial.
